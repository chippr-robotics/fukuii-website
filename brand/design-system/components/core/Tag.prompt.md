Small monospace protocol/capability tag — used in the protocol compatibility matrix and EIP/feature lists.

```jsx
<Tag tone="green">EIP-4844</Tag>
<Tag tone="amber">Engine API V1–V4</Tag>
<Tag tone="muted">custom</Tag>
```

Colorways: `green` (default) · `blue` · `teal` · `violet` · `amber` · `muted`. Group several in a `.protocol-tags` row.
