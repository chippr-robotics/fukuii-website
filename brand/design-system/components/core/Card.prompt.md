Rounded surface card (`card-fk`). Soft green-tinted fill, hairline border; lifts and gains a gold glow on hover.

```jsx
<Card>
  <h3>Dual EL client</h3>
  <p>Native Ethash for ETC. Engine API for post-Merge Ethereum.</p>
</Card>
```

For bordered, sharp-cornered grid layouts use `Cell` instead — the brand leans on the cell grid for most structural content and reserves rounded cards for standalone features.
