The Fukuii lockup — `FUKUII` in DM Sans 700 with the mono sublabel, optionally the hex mascot logo.

```jsx
<Logo />                                                  {/* wordmark + sublabel */}
<Logo hex="assets/logo/fukuii-hex-logo.png" size="lg" stacked />  {/* hero */}
<Logo sublabel={null} size="sm" />                        {/* compact nav */}
```

The hex mascot is a sticker-style badge — present it on near-black at large sizes; use the wordmark alone where the mark would compete. Static SVGs live in `assets/logo/`.
