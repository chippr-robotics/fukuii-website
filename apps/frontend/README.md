# fukuii-website / apps/frontend

Next.js 16 application for https://fukuii.com.

See the [root README](../../README.md) for full repo structure, deployment options, and brand guidelines.

## Commands

```bash
pnpm install
pnpm dev         # → http://localhost:3000
pnpm build       # production build
pnpm lint        # ESLint
pnpm typecheck   # tsc --noEmit
pnpm start       # serve production build
```
