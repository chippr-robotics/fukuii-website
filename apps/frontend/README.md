# fukuii-website / apps/frontend

Astro 5 static site for https://fukuii.com, deployed to GitHub Pages.

See the [root README](../../README.md) for full repo structure, deployment options, and brand guidelines.

## Commands

```bash
pnpm install
pnpm dev         # → http://localhost:4321
pnpm build       # astro check + static build to dist/
pnpm preview     # serve the production build locally
pnpm lint        # ESLint
pnpm typecheck   # astro check
```
